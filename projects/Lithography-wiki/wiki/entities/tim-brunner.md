# Tim Brunner

Tim Brunner 是本章具名的 phase-shift focus monitor 開發者，其方法以 mask 上的 90° phase shift 將焦距誤差轉換為晶圓上的位置誤差。

## 方法貢獻

位置誤差可透過 overlay 量測讀出，並包含焦距偏移方向，克服一般 CD 近似二次焦距響應的方向歧義。

本章指出，此方法需要特殊 phase-shift 區域，通常不能置入產品 reticle，因此是 test mask 方法，不等同產品晶圓上的常態監控；比較見 [[雙標靶劑量與焦距監控]]。
