# 自然解析度

自然解析度是特殊光罩圖案趨近極限時，影像尺寸主要由波長、NA 與量測閾值決定，而不再由光罩特徵尺寸決定的尺度。

## 三種極限圖案

| 圖案／模型 | 閾值或條件 | 影像寬度 |
|---|---|---|
| COG contact PSF | intensity threshold = 0.25 | 約 \(0.705\lambda/NA\) |
| 6% EPSM contact PSF | intensity threshold = 0.25 | 約 \(0.595\lambda/NA\) |
| coherent LSF | intensity threshold = 0.25 | \(0.603\lambda/NA\) |
| isolated 180° phase edge | intensity level = 0.25–0.3 | \(0.26–0.29\lambda/NA\) |

- **PSF**：暗背景中的孔縮至極小時，正規化影像趨近 [[點擴散函數]]。進一步縮小光罩孔主要降低峰值光強。
- **LSF**：暗背景中的透明槽縮至極窄時，影像趨近 line spread function；其結果依照明同調性而異。
- **isolated phase edge**：0° 與 180° 區域間的無寬度邊界仍形成窄暗線，其尺度不是光罩暗線寬度。

## 使用限制

以上數值必須與閾值及成像假設一起使用，不能當作硬性製造截止。極小孔的光通量趨近零，實際曝光時間也成為限制。

6% EPSM contact PSF 相較 COG 約窄 16%，但伴隨較強 sidelobes；不能只以主峰寬度判定成像可行性。

自然解析度也不能取代要求 DOF、曝光裕度及光阻輪廓規格的特徵解析度。來源見 [[19-optical-lithography--9-10-ch10--y2hwiy]]。
