# 焦距與曝光製程窗口

焦距與曝光製程窗口是焦距、曝光劑量平面上，所有指定微影品質規格同時成立的區域。它描述製程能力，須與實際誤差分布所代表的製程需求比較。

## 建立方式

focus–exposure matrix 同時改變焦距與劑量。Bossung plot 將每個劑量下的 CD 隨焦距變化畫成曲線；將 CD 上下限、sidewall angle 及 resist loss 限制改畫為等值線，即可求出規格交集。

量測噪聲與 feature model 擬合方式會影響窗口邊界，不能將量測模型選擇忽略為純粹儀器問題。

## EL 與 DOF 的取捨

以內接矩形表示固定範圍誤差，以內接橢圓表示假定 Gaussian 誤差的等密度輪廓。不同內接形狀給出不同曝光容忍度與焦距容忍度組合。

單一 DOF 必須同時指定：

- 圖形種類、尺寸及 pitch。
- CD、輪廓與其他適用規格。
- 可接受曝光範圍。
- 誤差分布與窗口評估方式。

因此製造 DOF 是 [[離焦與焦深]]的條件化延伸，不是只由波長及 NA 決定的常數。

## isofocal point 與交疊窗口

isofocal dose 對应焦距敏感度最低的 CD；該 CD 與目標 CD 的差稱 isofocal bias。偏差使窗口彎曲，降低可容納的誤差範圍。

不同關鍵圖形須共用曝光條件，因此應交疊窗口。不同場位置的同一圖形亦須交疊，以得到 UDOF。SRAFs 在本章示例中減少 isolated line 的 isofocal bias，改善與 dense line 的交疊窗口。

## 機率限制

二維等密度橢圓不是自動具有一維 ±3σ 的 99.7% 覆蓋率。相關誤差或混合系統性／隨機誤差需要額外建模；見 [[製程窗口橢圓應採何種聯合覆蓋率]]。
