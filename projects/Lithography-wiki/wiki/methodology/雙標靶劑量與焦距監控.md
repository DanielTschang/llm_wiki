# 雙標靶劑量與焦距監控

雙標靶劑量與焦距監控使用兩個對劑量及焦距有不同響應的圖形，避免單一 CD 回饋將焦距漂移誤認為劑量漂移。

## 設計理由與流程

單一 device-representing target 的 CD 變化可能來自兩種變數；以劑量補償可使 CD 看似穩定，卻令製程偏離最佳焦距並縮小可用窗口。

本章策略為：

1. 找到在 nominal dose 附近具 isofocal 行為的 dense target。
2. 選取焦距敏感、劑量斜率近似相同的 isolated target。
3. 以 dense CD 監控劑量，以 dense／isolated CD 差監控焦距大小。
4. 對兩者建立 focus–exposure 模型，使用聯合反演改善不完美標靶的辨識。

Figure 8.27 使用 90-nm dense line、220-nm pitch 與 80-nm isolated line，在示例範圍達約 10× 變數辨識能力；這不是跨產品保證值。

## 焦距方向限制

近似二次 CD 響應只能辨識焦距偏差大小，不能可靠判別正負方向。

[[tim-brunner]]的 90° phase-shift monitor 可轉換為有方向的位置誤差，但通常需要 test mask。scatterometry 則可利用 resist height 與 sidewall angle 的不對稱響應，在產品標靶上補充方向資訊。
